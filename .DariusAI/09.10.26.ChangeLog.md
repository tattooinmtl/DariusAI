## SESSION — 09.10.26 — Session-3 — installer verified end to end, website rebuilt

- `install.ps1` bugs found by running it for real (fresh install + update
  into a scratch folder, scratch user profile, from a zip of the code):
  - Python check piped `py --version` straight into `Select-Object -First 1`,
    which stops the pipeline, kills py.exe and leaves `$LASTEXITCODE` at -1:
    a random "Could not run Python via 'py'". Reproduced 6/6, fixed.
  - Em-dashes in a BOM-less UTF-8 file: Windows PowerShell 5.1 reads it as
    cp1252 and `.\install.ps1` had 8 parse errors (the `irm | iex` path was
    fine). Script is now pure ASCII; 0 parse errors both ways.
  - Output of pip / import-addon / install-shortcuts leaked into
    `Initialize-Install`'s return value, so the final "installed" line
    printed the whole import report. Now `| Out-Host`.
  - `$args` (automatic variable) renamed to `$roboArgs`.
- New options: `-ZipFile` (install from a local archive; also how the
  installer is tested before a push) and `-Dev` (pytest). Default install
  no longer pulls the dev extras.
- Result: fresh install 146 s, update 41 s, ~181 MB; the installed copy
  serves alpha 0.94 with a 228-node brain.
- Website `C:\Darius-ai website\` rebuilt for 0.94 (old copy in
  `C:\Darius-ai website.backup-2026-08-28\`): new screenshots from a demo
  brain with conversation nodes removed, install guide + FAQ (update,
  custom folder, zip, Python missing, error log, uninstall), what's new.
  Checked at 1440 px and 390 px (no overflow, no JS errors).
